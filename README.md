## 📌 Overview

**Delhi PureAir Dashboard** is a frontend-focused web application designed to raise awareness about air pollution in Delhi.  
It converts raw PM2.5 values into meaningful health insights using visual indicators and clean UI components.

The project emphasizes:
- Environmental awareness  
- Data clarity  
- User experience  
- Modern frontend development practices  

---

## ✨ Key Features

- 📊 PM2.5 air quality visualization  
- ❤️ Health impact estimation from pollution levels  
- 🌗 Dark & Light mode support  
- 🎨 Glassmorphism-inspired modern UI  
- ⚡ Fast and responsive design  
- 📱 Fully responsive (Desktop & Mobile)

---

## 🧠 Health Insight Logic

PM2.5 values are mapped to health risk levels using commonly accepted environmental research approximations.  
This helps users understand **how air pollution affects the human body** in a relatable way.

> Example:  
Higher PM2.5 → Increased respiratory & cardiovascular risk
